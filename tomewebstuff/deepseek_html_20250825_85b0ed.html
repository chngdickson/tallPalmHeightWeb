Keeping Footer at Bottom of Page

Various techniques to ensure your footer always stays at the bottom

Having your footer stick to the bottom of the page when content is scarce is a common challenge in web development. Below are different methods to achieve this, along with code examples and live demos.

Method 1: Flexbox Approach

The most modern and recommended approach using CSS Flexbox.

body {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}

main {
  flex: 1;
}

This is the main content area. When content is short, the footer will still push to the bottom.

Footer (always at bottom)

This method uses flexbox to push the footer to the bottom. The body is set to a column flex container with minimum height of 100vh. The main content has flex:1 to take up all available space.

Method 2: Grid Approach

Using CSS Grid to keep the footer at the bottom.

body {
  display: grid;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}

This is the main content area. The grid approach also works well for keeping footer at bottom.

Footer (always at bottom)

CSS Grid can also solve this problem efficiently. The body is set to grid layout with three rows: auto for header, 1fr for main content, and auto for footer.

Method 3: Negative Margin

A classic approach using negative margins.

html, body {
  height: 100%;
}

.wrapper {
  min-height: 100%;
  margin-bottom: -60px; /* Footer height */
}

.footer {
  height: 60px;
}

This method requires knowing the footer height and using negative margin to pull it up.

Footer (always at bottom)

This older technique uses a wrapper with minimum height of 100% and a negative margin equal to the footer height. It requires knowing the footer height in advance.

Method 4: Calc() Function

Using the calc() function to determine minimum height.

main {
  min-height: calc(100vh - 60px);
/* 60px is header height + footer height */
}

The calc() approach subtracts the combined height of header and footer from 100vh.

Footer (always at bottom)

This method uses the calc() function to set the main content height to 100vh minus the header and footer heights. It requires knowing these heights in advance.
